# 立体绘本 V5 · 参考效果迭代

参考：https://x.com/sonia_code/status/2098389067339849788

本轮根据原帖视频可见构图及作者展开的体验说明迭代：书架、桌面、摊开的书保持在同一阅读画面；左侧纸质故事卡和右侧立体舞台；绘本封面展示在背景书架上，可直接点击换书；立体物收回纸面后翻页，下一幕重新立起。保留三本原创故事、十二幕内容与 Edge 云端 TTS 预生成 MP3。

新增曲面纸页、多层书口、书签、木桌纹路、纸张凹凸纹理、枝叶层次、小狐狸脸颊与眉毛细节。点击角色会出现对应当前章节的对白，答对问题显示故事星星反馈。仍为程序化风格的 3D 角色，并非参考视频中角色细节的逐像素复刻。

## 启动

```sh
npm install
npm run dev -- --host 127.0.0.1
```

打开 http://127.0.0.1:5173/?library=children&v=5 。已有本地章节进度会继续保留。

## 检查

三本 × 四幕：收起、翻页、立起顺序，角色默认运动，Edge 音频播放；390px 布局；翻页中退出取消。浏览器测试无控制台错误。生产构建通过，保留 Three.js 单包体积警告。演示视频为无声录屏，实际页面可播放朗读。

## 实测归因

原始雨夜书房 V1 的 Atria API 生成记录沿用原项目材料。本轮 V5 与 V2—V4 后续交互均由 Codex 实现；原有封面来自 Image，朗读来自 Edge TTS。不能将本轮所有效果写为 Atria 独立生成。
