# 立体绘本 · 翻书与动态场景版

启动：`npm install`，然后 `npm run dev -- --host 127.0.0.1`。打开 `/?library=children` 进入绘本馆。

## 本轮变化

- 封面从点击处移动到眼前，沿书脊翻开，显露内页后接入立体场景。房间内的绘本取阅时隐藏，退出后归位。翻幕也有纸页动画。可按 Esc 中断，重新进入仍能操作。
- 12 段朗读全部改为 Microsoft Edge 云端 TTS，音色 zh-CN-XiaoxiaoNeural（晓晓），语速 -12%，总计约 330 秒。使用 edge-tts 7.2.8 预生成 MP3，运行时读取 public/audio-edge/。无须在浏览器运行时提供密钥。旧 public/audio/ 是历史本机合成音，当前代码已不再引用。
- 森林：狐狸走动、尾巴与灯笼摆动、树木摇摆、落叶和萤火飞行；溪桥流水、小蜗牛和小屋烟雾依章节加入。
- 海洋：鲸鱼摆尾巡游、鱼群绕行、气泡上升、水纹扩散、海草摆动；海龟水道与声波光环依章节加入。
- 月面：月兔默认低重力跳跃、星星和地球转动、火箭着陆与尾焰；后续章节加入浇水动作、水滴与花园光环。

七组浏览器检查通过，包括 12 幕默认运动和音频、取出翻开、动画中途取消、翻幕中途退出、窄屏布局。详见交付目录 v4-test-results.json。构建通过，仍有 JS 包体积提示。

所有新增交互与模型由 Codex 实现，不能记为 Atria 的独立输出。这是屏幕内 3D 绘本，未接入摄像头 AR。

Edge TTS 工具文档：https://github.com/rany2/edge-tts
