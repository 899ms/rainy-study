# 雨夜书房 · AFTER HOURS

一间可以在浏览器里读书、写画、听故事的 3D 书房。窗外下雨，桌上亮灯，书架上的书可以拿下来翻阅。

**[在线体验](https://andyhuo520.github.io/rainy-study/)** · **[直接打开立体绘本](https://andyhuo520.github.io/rainy-study/?library=children)**

![雨夜书房](docs/room.png)

## 可以做什么

- 全景、书架、书桌、窗边四个机位，自由拖动和缩放，收藏机位并在刷新后恢复。
- 雨夜与晴日切换，窗景、光线、雨滴与环境音。
- 三本普通书，每本三章，取出、翻页、阅读、放回。
- 拿起纸笔手写，调颜色和粗细，撤销、重做、保存、导出 PNG；笔迹保留在桌面纸上。
- 三本儿童立体绘本，共十二幕故事：狐狸的森林、鲸鱼的海底、月兔的花园。
- 立体场景默认运动，点击角色出现对白；角色收起后翻页，下一幕再立起。
- 十二段中文合成朗读、知识卡与互动提问。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，开发时使用 Node.js 24。

```sh
npm ci
npm run dev
```

打开终端显示的地址。页面不需要 API key，不调用模型接口。文字、模型和媒体资源随项目提供；笔迹、阅读进度及收藏仅存于当前浏览器。

```sh
npm run build
npm run preview
```

构建结果在 `dist/`，可部署到静态托管平台。资源使用相对路径，支持 GitHub Pages 项目子目录。

## 项目来源

项目起于一次 [Atria Dawn Preview](https://github.com/atria-asi/Atria-Dawn-Preview) 的真实 AI coding 体验。Atria 通过 API 生成初版书房主体与多轮补丁；Codex 组织脚手架、运行、反馈和验证，并做了墙体与事件选择器等直接收尾。

后续取放阅读、手写纸笔、玻璃雨滴、立体绘本、动态场景及本次部署由 Codex 实现。封面和书内插图来自 Image，儿童朗读为 Edge TTS 预生成音频。最新效果不能全部归因于 Atria 独立生成；本项目也不构成跨模型基准评测。

这是独立体验作品，与 Atria 官方不存在隶属关系。原始 API 请求、体验密钥和私有媒体 brief 不包含在仓库中。

## 使用范围与限制

- 浏览器内的 3D 立体绘本，没有摄像头或现实空间定位 AR。
- 环绕观察与预设机位，没有第一人称碰撞和行走系统。
- 月球种植故事包含童话想象。模型、雨滴和声音都是风格化模拟。
- 已检查桌面与 390px 移动布局及主要交互，尚未完成真实儿童研究、长期性能或所有设备兼容验收。
- 浏览器首次播放音频需要用户点击。

## 发布更新

源码位于 `main`，构建后的静态文件发布在 `gh-pages`。重新构建后，将 `dist/` 内容提交到 `gh-pages` 即可触发 GitHub Pages 更新。不要将 `node_modules`、密钥或 `.env` 文件提交到仓库。
